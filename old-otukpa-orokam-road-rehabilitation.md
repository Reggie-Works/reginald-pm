# Old Otukpa–Orokam Road Rehabilitation

**Project Role:** Project Manager  
**Project Location:** Otukpa, Ogbadigbo LGA, Benue State, Nigeria  
**Project Category:** Road Infrastructure / Rehabilitation  
**Project Status:** Completed

## 1. Project Overview

The Old Otukpa–Orokam Road Rehabilitation project involved targeted pavement rehabilitation and remedial works to address deteriorated road sections, potholes and erosion-related pavement damage.

The intervention focused on restoring affected pavement sections, improving road surface conditions and addressing drainage-related issues through coordinated rehabilitation activities.

## 2. Project Scope

Key work activities included:

- Site clearing and preparation.
- Drainage repairs and desilting.
- Laterite sub-base construction.
- Stone base construction.
- Asphalt pavement patching.
- Asphalt wearing course overlay.
- Remedial works on erosion-damaged pavement sections.

## 3. Key Project Quantities

| Work Description | Quantity |
|---|---:|
| Site clearing | 1,600 m² |
| Drain repair | 25 m |
| Drain desilting | 200 m |
| Laterite sub-base | 320 m² |
| Stone base | 320 m² |
| Asphalt wearing course | 1,600 m² |

## 4. Project Management

As Project Manager, my involvement centred on coordinating project operations and facilitating the execution of the rehabilitation works.

Key management areas included:

- Site operations and activity coordination.
- Materials and logistics coordination.
- Resource allocation and utilisation.
- Work sequencing and execution monitoring.
- Coordination of construction activities.

## 5. Project Outcome

The rehabilitation works addressed identified pavement defects through asphalt overlay, pothole repairs, drainage interventions and remedial pavement works.

The project provided an opportunity to apply practical project management principles within a road infrastructure rehabilitation environment.
